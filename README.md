## 🧠 Learning Philosophy

Strong computational biology requires understanding **both sides of the bridge**: the biological problem and the computational method used to investigate it.

```text
BIOLOGY
   ↓
Biological Question
   ↓
Biological Data
   ↓
Computational Method
   ↓
Analysis
   ↓
Interpretation
   ↓
Biological / Technical Insight
   ↓
Build → Test → Improve
```
